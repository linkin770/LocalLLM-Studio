解释量子计算
你

量子计算是一种基于量子力学原理的新信息处理范式，利用量子系统（如量子比特或量子位）的叠加和干涉特性，实现对复杂问题的高效计算。以下是量子计算的核心解释：

  1. 量子比特（Qubit）：
    传统计算机使用比特（bit），只能处于 0 或 1 的状态。而量子比特（qubit）可以同时存在于 0 和 1 的状态上，利用叠加原理，能实现并行计算。
  2. 量子纠缠：
    量子比特之间可以通过量子纠缠相互关联，即使相隔遥远，状态却能瞬间影响对方，这种非局域的关联性是经典计算机无法实现的。
  3. 量子叠加：
    qubit 可以处于多个状态的叠加，例如 0 和 1 的混合态，这使得计算过程不再是线性的，而是可以同时处理多种可能性。
  4. 量子干涉：
    量子系统的波函数会通过干涉现象强化或消减某些状态的概率，导致计算结果的非随机性，有助于揭示隐藏的规律。
  5. 量子算法：
    如 Shor 算法、Grover 算法等，利用量子优势解决经典计算机难以解决的难题，如整数分解和加密破解。
  6. 应用场景：
    量子计算在密码学、优化问题、材料科学等领域展现出潜在优势，但随着量子纠错技术和规模限制，当前仍面临挑战。

FEATURES

三件事，做到极致

01

跑服务

启动 / 停止 llama-server，健康检查，实时日志。系统托盘后台运行，最小化后服务继续工作。

02

聊模型

内置流式聊天界面。Markdown、代码高亮、上下文使用率环形进度、每会话独立提示词。

03

接外部

标准 /v1/chat/completions 流式接口。Claude Code、OpenClaw、任何 OpenAI 客户端直接连。

DESIGN PHILOSOPHY

克制，是最高级的清晰

三个原则贯穿整个产品。我们不堆功能，也不学 macOS 的皮毛，而是让设计真正服务于本地大模型这一具体场景。

I

Clarity

清晰

UI 退后，模型输出是绝对主角。每一个像素的留白都经过计算，让用户的注意力停留在真正重要的地方。

  • 无装饰性渐变
  • 无多余边框与阴影
  • 字号阶距 1.25× 严格比例
II

Deference

退让

界面服务于内容，从不与之竞争。系统级字体、系统级颜色，让操作台自然融入 Windows 桌面环境。

  • SF Pro 优先，MiSans 兜底
  • 系统级滚动条与焦点环
  • 不抢焦点的次要操作
III

Depth

层次

用极克制的层次区分元素。1px hairline、4px 阴影、3px 透明 ring，构建可触摸的视觉深度。

  • 三层灰阶：0.04 / 0.08 / 0.12
  • backdrop-filter 仅用于顶栏
  • 动效 240ms cubic-bezier ease-out

COLOR

色彩

主色系统由 4 组语义色阶组成，每组 5 个递进。绿色仅用于成功状态，不做装饰。

INK · 墨色

#08090a · #1d1d1f · #424245 · #86868b · #b8b8be

BG · 底色

#ffffff · #fafafa · #f5f5f7 · 4% black · 6% black

LINE · 描边

4% · 8% · 12% · 20% · 100%

STATUS · 状态

success · starting · danger · link · accent
